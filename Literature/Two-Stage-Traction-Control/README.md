## 使用这些结论时的边界

- **预测准确不等于物理参数唯一辨识。** 能力表征可以由未来加速度、轮速和车速响应支持其控制价值，但不能无额外激励和独立测量就断言恢复真实 μ 或全部土壤参数。
- **模型验证不等于控制器验证。** 03 没有完成闭环控制器实验；02 改善的是模型与 MPPI 驾驶表现，不是轮端转矩滑移控制；01 的履带速度接口与小车横向接口也不可直接照搬。
- **残差的作用位置必须标清。** 动力学力残差、加速度策略残差、轮端转矩补偿和增益调节不是同一方法。
- **指标不跨论文排名。** 位置 RMS、轨迹末端预测误差、轮速绝对误差、圈速和滑移 RMSE 的任务与单位不同；百分比只在对应论文工况及基线内解释。
- **软土不只是道路 μ 变化。** CarSim 可作车辆／执行器及结构化附着基线，松软地形的沉陷、剪切及历史作用需要额外模型或实测证据。
